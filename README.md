# Cyberthon 2024 – 1st Place Winning Project
## Overview
This project was awarded 1st Place in Cyberthon 2024 and presents an innovative conceptual design for promoting cybersecurity awareness among children, adults, and people with visual and hearing impairments.

The project proposes accessible and inclusive learning tools that make cybersecurity education more engaging and easier to understand for different groups of society.

> **Note:** This is a conceptual design project created for the Cyberthon 2024 competition. The proposed tools were not physically developed or implemented. They are presented as prototypes and design concepts.

## Project Objectives
- Promote cybersecurity awareness among different age groups.
- Make cybersecurity education more accessible for people with disabilities.
- Design engaging and inclusive learning experiences.
- Support innovative approaches to cybersecurity education.

## Proposed Solutions
### For Children (6–12 Years)
- An AI-powered educational robot with an interactive smart board that teaches cybersecurity concepts in an engaging way.
- A small audio device that delivers cybersecurity stories and cartoons for visually impaired children.
- A robot that teaches cybersecurity using sign language for hearing-impaired children.

### For Adults (13+ Years)
- A modern educational application for learning cybersecurity concepts.
- An AI-powered radio that provides accessible audio-based cybersecurity education for visually impaired users.
- An interactive smart board that teaches cybersecurity through sign language for hearing-impaired users.
